
# Conecta Fácil — CSS e Acessibilidade

## Sobre o projeto

Este é o segundo miniprojeto do Conecta Fácil, uma iniciativa que busca facilitar o aprendizado de tecnologia para idosos.

Nesta etapa, desenvolvi uma página utilizando HTML e CSS, com foco na organização visual e na legibilidade.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub
- Visual Studio Code

## O que aprendi

- Conectar um arquivo CSS ao HTML
- Alterar cores, fontes e tamanhos
- Utilizar margin e padding
- Criar cartões com div e class
- Aplicar bordas e cantos arredondados
- Controlar a largura dos elementos
- Melhorar o espaçamento entre linhas

## Próximas etapas

Continuar desenvolvendo o Conecta Fácil, adicionando novos conteúdos, recursos de acessibilidade e funcionalidades interativas.
